# Game Performance Analytics Dashboard 🎮📊

## 🧠 Overview
This project demonstrates the integration of a Unity-based game with a Python analytics system to analyze player performance.

## 🚀 Features
- Collects gameplay data from Unity
- Processes data using Python
- Visualizes player performance
- Generates insights for improvement

## 🛠 Tech Stack
- Unity (C#)
- Python (Pandas, Matplotlib)
- Data Visualization
